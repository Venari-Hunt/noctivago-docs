Browse Sounds

Search Freesound.org and YouTube for ambient sounds, without leaving the app.

Don't already have the sound you want? The Browse Sounds tab searches two sources at once and shows the results together in one grid, each tagged with where it came from — no need to pick a source first.

Two sources, combined

SourceWhat you getPreview
Freesound.orgCommunity-uploaded sound effects and field recordings, each with a Creative Commons license, tags, a description, and a rating.Plays instantly in-app.
YouTubeAnything on YouTube — a lot of long-form ambience (rain, forest, city) lives here that Freesound doesn't have.A "Watch ↗" link opens the real video in your browser first, since there's no instant in-app preview for these.

Type a search, hit Enter (or the Search button), and scroll — more results load automatically as you reach the bottom, from whichever source(s) still have more to show.

Importing a result

Click Import on any card to add it to your library, exactly like anything else you've imported — it shows up in the Mixer ready to trim, filter, and mix in.

  • Freesound imports download only the compressed preview (not the uploader's original file) — plenty for a looping ambient sound, and near-instant.
  • YouTube imports download the audio through the same tool Noctívago's "Add from link" feature already uses, capped at 10 minutes so a search result doesn't pull down hours of audio you'll only ever loop a slice of.
A Freesound import keeps attribution automatically for any license that requires it (most Creative Commons licenses do) — you don't need to track that down yourself later.

If one source is unavailable

The two sources work independently. If Freesound search isn't available in your build, or a YouTube search fails for any reason, the other source keeps working on its own — you'll see a note about which one, but it never blocks the rest of the tab.
