Plugins & Settings

Noctívago is the Mixer plus the extras you choose. Everything else is a plugin you can install, update or switch off.

The official plugins

PluginWhat it adds
RemixThe per-sound editor: trim, filters, EQ, pitch, playback modes, Sound Groups.
ExportBake a mix down to an audio or video file.
CompositeCombine several sounds into one new sound on a small timeline.
Browse SoundsSearch Freesound and YouTube and import sounds.
CommunityShare presets and download other people's.

Each one lives in its own public repository under Venari-Hunt (noctivago-remix, noctivago-export, and so on) with its own releases.

Getting them

  • Already using Noctívago? Nothing to do. The first launch after the update installs the plugins you already had.
  • Fresh install? The Mixer shows an Add the extras card at the top. One click installs all of them. You can close it and add them later from Settings.

The Settings window

Click the gear icon in the Mixer toolbar. Settings opens as its own window with a sidebar:

  • General: updates, keep playing when closed, seamless-loop preparation.
  • Library: watched folders.
  • Community plugins: your installed plugins, each with an on/off switch and an Uninstall button, plus Restricted mode, Browse and Check for updates.
  • One page per plugin that has its own options, for example Browse Sounds' Freesound and YouTube settings.

Turning a plugin on or off applies after a restart; a banner offers Restart now.

Browsing, installing and updating

Browse opens the plugin list. Search it, sort by Most downloaded, Name or Recently updated, or show only what you have installed. Pick a plugin to read its description, see its download count and version, and install, update, switch on or off, or uninstall it.

Check for updates looks for new versions of everything you have installed; Update all installs them in one go. A plugin only updates to a version your copy of Noctívago can run, so an older app never gets a plugin it can't load.

Restricted mode

On by default. While it's on, only official plugins can be installed or loaded. To try a plugin made by someone else, turn Restricted mode off in Settings → Community plugins. Third-party plugins run with the same access as the app itself, so only install ones you trust.

Making your own

Start from the template repository noctivago-sample-plugin. Tagging a release builds and publishes it for you.

Noctívago is an independent, early-stage project. This documentation covers the app as it exists today and will grow alongside it.
