Getting started

Install Noctívago and build your first mix in a couple of minutes.

1. Install

Download the installer from itch.io and run it. It's a normal Windows installer (NSIS) — you can choose where it installs, and it adds a Start Menu shortcut.

Windows will show a SmartScreen warning the first time you run the installer, because it isn't code-signed yet. This is normal for a small independent app — see the FAQ for why, and a public virus scan of the file if you want to check it yourself.

2. Add your first sounds

On the Mixer tab, click the + button in the top toolbar. You can:

  • Add file… — pick one audio file (mp3, wav, ogg, flac, m4a, or opus).
  • Add folder as preset… — every audio file in a folder becomes one saved preset.
  • Add folder as tag… — every file in a folder gets tagged with the folder's name.
  • Watch a folder… — register a folder so anything dropped into it later is imported automatically.
  • Record audio… — record straight from your microphone.
  • Add from link… — paste a direct audio URL, or a YouTube/video-site link, and it downloads and imports it.

Don't have a file yet? The Browse Sounds tab searches Freesound.org and YouTube for you — search, preview, and import a result straight into your library.

3. Build a mix

Every sound in your library shows up as a row in the Mixer. Click Add (or the row's "In Mix" toggle) on each sound you want playing together, adjust each one's volume with its own slider, then hit the big Play all button in the toolbar to start (or stop) everything at once. The master Volume slider next to it controls the whole mix's overall level.

4. Save it as a preset

Once you like a mix, open Presets in the toolbar and save it under a name. Loading a preset later restores exactly which sounds were in it and at what volume — and once a preset is loaded, further tweaks (adding/removing a sound, dragging a volume) save back into it automatically, no extra step needed.

5. Shape a sound (optional, but this is where Noctívago goes deep)

Open the Remix tab and pick a sound to trim its loop point, add filters/EQ/reverb, or change how it plays (continuous loop vs. a randomized one-shot vs. a clock schedule). See the Remix docs for the full picture — nothing here is required to just get a mix playing, it's there for whenever you want more control over how a sound actually sounds.
